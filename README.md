# Animal Puzzle

**Play it at
[jbj.github.io/toddler-puzzle](https://jbj.github.io/toddler-puzzle/).**

A drag-and-drop shape puzzle for toddlers. Animals wait in a tray; each one is
dragged onto its matching animal-shaped hole. The game starts with a quick,
forgiving win, grows gradually, and deals every puzzle fresh.

It works with a finger or mouse on a screen of any shape. There is no menu on
the play surface and nothing the child needs to read.

```sh
npm install
npm run dev
```

Run `npm run verify` before opening a pull request.
